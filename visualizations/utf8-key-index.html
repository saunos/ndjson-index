Why keep hashes[i] and ends[i]? When the hash table doubles in size (at 50% load), grow() re-inserts every index using hashes[i] & newMask without touching bytes. And because keys sit back-to-back with no delimiter, index i's key is simply bytes.subarray(i === 0 ? 0 : ends[i - 1], ends[i]).
